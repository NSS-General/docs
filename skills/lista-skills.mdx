## ✅ Skills activos

### 📋 Onboarding — `/nss:onboarding`
Proceso completo de ingreso de nuevos clientes. **Modo supervisado.**

### 📄 Sync Docs — `sync docs`
Sincroniza docs.nss.cl con el estado actual de la operación.

## Flujo de Facturación

```
 Solicitud ──▶ ¿Cliente existe? ──▶ ¿Datos OK? ──▶ Crear factura CL34
                    │                    │              │
                    No ──▶ Crear         No ──▶ Pedir   ▼
                           cliente        datos     Confirmar ──▶ SII ──▶ PDF ──▶ 📎 Slack
```

> ⚠️ Solo documentos **exentos**. CL33 y CL39 están bloqueados a nivel de código.

## Cómo solicitar un nuevo skill

1. Habla con Clemente o Esteban
2. Definir proceso en un archivo SKILL.md
3. Agregar templates si aplica
4. Probar en modo supervisado
5. Activar trigger en el daemon y documentar aquí
